# Design skill catalog

Each link pins the reviewed skill and commit from the [design-skills list](https://github.com/stars/imnwngr/lists/design-skills). Check local revisions and available tooling before native invocation.

## Nutlope/hallmark

Use Hallmark for new page direction. On existing pages choose its named audit or redesign branch when specifically requested. Its helpers need Node and rendered checks need a browser. Verify the primary action and compare the page with the agreed direction. [Upstream skill](https://github.com/Nutlope/hallmark/blob/04977e15f3dfd6ee4b74c887dac3eb52665d6c92/skills/hallmark/SKILL.md)

## Leonxlnx/taste-skill

Choose for a brand-led website with suitable editorial content and assets. Its full build and finish workflow uses Node 22+ and Chrome, Edge or Chromium. Check image cropping and exercise the main action on phone and desktop. Keep one visual direction throughout. [Upstream skill](https://github.com/Leonxlnx/taste-skill/blob/f6b76575f949707b4e3c37cd86cb44b0b98643e8/skills/taste-skill/SKILL.md)

## nextlevelbuilder/ui-ux-pro-max-skill

Research design tokens and patterns across screens. Inspect existing tokens first. The search helper uses Python 3 and repository data. Resolve plugin paths against the checkout. Use non-persisting queries during planning and test recommendations on representative component states. [Upstream skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/e59ff376a41f7ca47b7541ad5c116495cbade3ee/.claude/skills/ui-ux-pro-max/SKILL.md)

## jakubkrehel/skills

Review a screen with better-interface or a diff with interface-review. Select the layout, writing or accessibility module for a specific issue. Identify the element, user impact and reproduction. Confirm interactions in a browser. [Upstream skill](https://github.com/jakubkrehel/skills/blob/276449adf5fa509adaab842b3559cb375ca868a4/skills/better-interface/SKILL.md)

## pbakaus/impeccable

Use the Codex entry for a scoped critique, audit or polish pass. Select the method for the observed problem. Check native command availability before invoking it. Rank findings by impact or compare the affected screen before and after a requested change. [Upstream skill](https://github.com/pbakaus/impeccable/blob/d41d9860b0094dcb68030657da63461212835aaa/.agents/skills/impeccable/SKILL.md)

## miqdadbadjuber/anti-slop

Apply the quality filter after establishing direction. Select modules for copy, accessibility and responsive behavior as needed. The rules are readable directly. Runtime checks need a working project and browser. Trace each failure to a visible element, control or state. [Upstream skill](https://github.com/miqdadbadjuber/anti-slop/blob/57b92d497a67c226b060b71c6f263c8631f37da4/skills/antislop/SKILL.md)

## greensock/gsap-skills

Use for a feature that needs GSAP. Select the matching timeline, framework or ScrollTrigger module. Check installed library and plugin versions. Verify replay, navigation cleanup and reduced motion. Simple transitions may be covered by existing CSS. [Upstream skill](https://github.com/greensock/gsap-skills/blob/aed9cfd3277740755f6bfc1155c7aa645403b760/skills/gsap-core/SKILL.md)

## nateherkai/scroll-craft

Use when scroll progress tells the story. Plan opening, transition and resting states. The full pipeline uses Node, ffmpeg, browser automation and a media provider. Prefer available assets when suitable. Check mobile and reduced-motion sequences. Route continuous camera flight to Scroll World. [Upstream skill](https://github.com/nateherkai/scroll-craft/blob/75d81f74e83692add18cd7a8a8e078b8a887a579/plugins/nateherk-design/skills/scroll-craft/SKILL.md)

## oso95/scroll-world

Use for a continuous camera flight through connected scenes. The native pipeline needs suitable media, ffmpeg/ffprobe and byte-range serving. Confirm approval for paid generation. Inspect frame continuity at scene seams and reduced-motion access. [Upstream skill](https://github.com/oso95/scroll-world/blob/71cc36d3bb150248ae36a2c552f9cbf88802a79c/skills/scroll-world/SKILL.md)

## CloudAI-X/threejs-skills

## img2threejs/img2threejs

Use for reconstructing an object from a supplied image as a procedural Three.js model. The native path uses Python state helpers in a full checkout plus Node and browser rendering. Match camera viewpoint to the reference and record shape, material and fidelity differences. [Upstream skill](https://github.com/img2threejs/img2threejs/blob/0c0c49bc168e648dbaf9c8c080474de0b3a941b6/SKILL.md)
